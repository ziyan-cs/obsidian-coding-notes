

## 开发环境

| 角色      | 设备 / 系统                                      | 说明                |
| ------- | -------------------------------------------- | ----------------- |
| 服务端     | VMware 虚拟机 · Ubuntu 24.04 LTS · `student-pc` | 服务器运行环境           |
| 客户端     | 宿主机 Windows · 同一局域网桥接                        | Telnet 连接测试       |
| 压测 / 扩展 | NanoPi R4S · OpenWrt                         | 多并发连接测试，v0.x 阶段引入 |

- 网络拓扑：
	- 宿主机与虚拟机通过 VMware 桥接模式处于同一局域网
	- R4S 接入同一交换机
