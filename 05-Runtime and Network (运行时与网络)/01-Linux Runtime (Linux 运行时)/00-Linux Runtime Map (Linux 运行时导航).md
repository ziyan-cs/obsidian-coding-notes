# 00-Linux Runtime Map (Linux 运行时导航)

> [!abstract] 阅读定位
>
> Linux 笔记用于解释服务运行时的资源、调度和 I O 行为；目标是能从进程、文件描述符、内存和系统调用定位问题。

## 学习顺序

1. `01–03`：Shell、文件系统、系统管理基础。
2. `04–13`：进程、线程、IPC、同步与信号。
3. `14–20`：I O 模型、epoll、触发方式与零拷贝。
4. `21–23`：系统调用、动态库、调试追踪。

## 实战问题

服务连接不释放、CPU 飙升、内存上涨或卡住时，先收集进程状态、fd、日志与 profile，再提出假设；不要凭“经验词”直接修改代码。
