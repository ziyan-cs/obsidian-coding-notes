# 00-CS Core Map (计算机核心导航)

> [!abstract] 阅读定位
>
> 计算机核心是后端性能、并发和运行时问题的共同底座；先理解程序如何变成指令与数据，再理解操作系统如何分配资源。

## 学习顺序

1. `01–03`：计算机系统、抽象层和软硬件边界。
2. `04–07`：二进制、整数、浮点和位操作。
3. `08–17`：CPU、存储层级、I O、操作系统与构建加载。
4. `18–28`：进程线程、虚拟内存、文件系统、同步、性能与系统思维。

## 学完后的能力

能解释一次 C++ 程序从编译到运行时，CPU、内存、操作系统分别做了什么；遇到慢、卡、错时知道先看哪一层。
