> [!abstract] 本篇要点
> 用交换论证或“领先不变量”证明贪心选择；用窗口谓词的单调性判断滑动窗口是否成立，并掌握区间与计数边界。

# 贪心不是“每次取最大”

贪心算法在每一步做局部选择，并且之后不回退。正确性必须来自问题结构，常见证明方式：

- **交换论证**：任意最优解都能把第一步换成贪心选择且不变差；
- **领先不变量**：处理任意前缀时，贪心方案至少不劣于其他方案；
- **归纳/切分**：选完一步后，剩余问题仍是同类最优子问题。

找不到证明时，应尝试构造反例，而不是把样例通过当作正确。

# 区间问题

## 最多不重叠区间

按结束时间升序排序，每次选择起点不早于上一个已选结束点的区间。交换论证：任何最优解的第一个区间都可换成结束最早者，它给后续留下的空间不少。

端点是否允许接触取决于区间是闭区间还是半开区间；`start >= end` 与 `start > end` 不能凭习惯选择。

## 合并区间

按起点排序，维护当前合并区间 `[left, right]`：新起点未越过 `right` 时扩展右端，否则输出当前区间并开始新段。它是一种排序后线性扫描，不必强行用“局部最优”解释。

# 跳跃与覆盖

跳跃游戏判断可达性时维护已处理前缀可到达的最远位置 `farthest`。若当前位置超过它，说明出现不可跨越断点。求最少跳数则按层维护“本层边界”和“下一层最远边界”，本质接近隐式图 BFS；不要在每个位置都立刻增加步数。

# 滑动窗口成立的条件

窗口 `[left, right]` 随 `right` 向右扩张；当约束不满足时移动 `left` 恢复。线性复杂度来自每个端点最多前进 `n` 次。

它要求窗口状态能增量维护，并且收缩方向具有可预测性。例如全正数数组中，扩大窗口不会减小和，适合求和阈值；含负数时这一单调性消失，普通滑窗可能漏解。

## 无重复字符最长子串

用映射记录字符最后出现位置，左端只向右移动：

```cpp
std::size_t longest_unique(std::string_view s) {
    std::array<std::size_t, 256> last;
    last.fill(std::string_view::npos);
    std::size_t left = 0, answer = 0;
    for (std::size_t right = 0; right < s.size(); ++right) {
        unsigned char c = static_cast<unsigned char>(s[right]);
        if (last[c] != std::string_view::npos)
            left = std::max(left, last[c] + 1);
        last[c] = right;
        answer = std::max(answer, right - left + 1);
    }
    return answer;
}
```

此代码按字节处理，适合约定为 ASCII/字节串的题目；UTF-8 文本需要先按所需字符语义解码。

## 最小覆盖子串

维护目标计数 `need`、窗口计数 `window` 和已经满足数量。右端扩张直到覆盖全部需求，再反复收缩并更新最短答案。若目标含重复字符，“满足种类数”和“窗口总字符数”不能混为一谈。

## 固定长度窗口

固定长度 `k` 时，每次加入右端元素并在长度超过 `k` 时移除左端；当长度恰为 `k` 再更新答案。`k=0`、`k>n` 的返回语义应由接口明确。

# 何时换工具

| 条件 | 更可能的工具 |
|---|---|
| 正数数组、窗口和阈值 | 双指针/滑窗 |
| 含负数的区间和 | 前缀和 + 哈希/单调队列 |
| 固定长度聚合 | 固定窗口 |
| 区间最大/最小值 | 单调队列 |
| 需要回退选择 | DP、搜索或其他全局算法 |

# 考察题目

## 1. 动手题

实现最短满足和的滑动窗口，加入负数输入找出原算法失效例子；说明需要什么前提。

> [!note]- 验收要点
> 正数数组下窗口和随边界单调变化；有负数时收缩可能漏解，需换前缀和等方法。

## 2. 机制追问

什么时候能用滑动窗口，什么时候贪心选择需要证明？

> [!note]- 参考答案
> 窗口要能在移动边界时单调维护约束，负数等条件可能破坏单调性；贪心需交换论证或不变量证明局部选择不会排除全局最优。
