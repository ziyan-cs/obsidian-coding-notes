# 00-Algorithms MOC (算法导航)

> [!abstract] 阅读定位
>
> 算法不是背题解，而是识别「问题模式 → 数据结构 → 时间复杂度」；模板库负责记忆，错题本负责复盘。

- 基础数据结构：[[01-Array & Two Pointers (数组与双指针) ⭐|数组与双指针]] · [[02a-Reversal, Cycle Detection, Merge (反转⧸判环⧸合并)|链表]] · [[03a-Monotonic Stack (单调栈)|单调栈]] · [[04-Hash Table (哈希表) ⭐|哈希表]] · [[05a-Top-K Problems (TopK问题模板)|堆与 TopK]]

## 学习顺序
1. 基础数据结构（数组/链表/栈队列/哈希/堆）→ 2. 树与图 → 3. 核心算法（二分/排序/DP/贪心）→ 4. 字符串与位运算，配合模板库与错题本滚动复盘。
