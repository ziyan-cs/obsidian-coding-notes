# 00-Algorithms Map (算法导航)

> [!abstract] 阅读定位
>
> 算法训练的目标是识别模式、选对数据结构并证明复杂度，而不是背诵孤立题解。

## 学习顺序

1. `01–07`：数组、链表、栈队列、哈希、堆与 Top K。
2. `08–14`：树、图、并查集、最短路与二分。
3. `16–19`：排序总览与三类核心排序。
4. `20–27`：动态规划、贪心、滑动窗口、字符串和位运算。

## 练习闭环

每题记录：识别到的模式、关键不变量、复杂度、一个易错边界。模板放 `03-Foundation Practice`，错题写入 `01-Algorithm Mistake Journal`。
