# 命题、蕴含与量词

命题是具有真假值的陈述。复合命题常用：

| 形式 | 含义 | 何时为假 |
|---|---|---|
| `P ∧ Q` | P 且 Q | 任一为假 |
| `P ∨ Q` | P 或 Q（包含两者都真） | 两者都假 |
| `¬P` | 非 P | P 为真 |
| `P → Q` | 若 P，则 Q | P 真且 Q 假 |
| `P ↔ Q` | P 与 Q 等价 | 真值不同 |

`P → Q` 与逆否命题 `¬Q → ¬P` 等价，但与逆命题 `Q → P` 不等价。例如“请求超时则未按时完成”不能反推出“未按时完成一定表现为客户端超时”。

量词的否定必须同时翻转量词与内部命题：

```text
¬(∀x, P(x))  ≡  ∃x, ¬P(x)
¬(∃x, P(x))  ≡  ∀x, ¬P(x)
```

所以推翻“所有输入都正确”只需一个合法反例；证明“存在解”可构造一个实例，而证明“不存在”必须排除全部候选。

# 证明方法与程序正确性

- **直接证明**：从前提按定义和已知定理推出结论。
- **逆否证明**：当否定结论更容易使用时证明 `¬Q → ¬P`。
- **反证法**：假设结论为假并推出矛盾。
- **数学归纳法**：证明基例，再证明 `P(k) → P(k+1)`。
- **构造证明**：给出满足条件的对象或算法。
- **反例**：推翻全称结论，不等于证明相反的全称命题。

## 循环不变量

证明循环正确通常分三步：

1. 初始化前不变量成立；
2. 一轮循环保持不变量；
3. 终止条件与不变量共同推出后置条件。

二分查找的不变量可表述为“若目标边界存在，它始终在当前搜索区间内”；终止性还要求每轮严格缩小良基度量，例如区间长度。

递归正确性类似归纳证明：基例正确，递归调用处理严格更小问题，组合步骤把子问题答案变为原问题答案。只证明“结果正确”而不证明“会终止”是不完整的。

# 集合、关系与函数

集合运算包括并、交、差、补和笛卡尔积。德摩根律连接逻辑与集合：

```text
(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
```

关系是笛卡尔积的子集。常见性质：

- 等价关系：自反、对称、传递，会把集合划分为等价类；
- 偏序：自反、反对称、传递，元素不必两两可比；
- 全序：偏序基础上任意两元素可比。

版本依赖、锁层级常是偏序；排序比较器需要严格弱序。把“不可比”误作“相等”会破坏有序容器与算法假设。

函数可讨论单射、满射和双射。哈希函数通常不是单射，因此冲突不是异常；主键到记录的映射则要求键唯一。

# 计数与复杂度直觉

## 基本原则

- 加法原理：互斥方案集合的规模相加；
- 乘法原理：连续独立选择步骤的选择数相乘；
- 排列：从 `n` 个不同元素选出并排列 `k` 个，`P(n,k)=n!/(n-k)!`；
- 组合：只关心集合，`C(n,k)=n!/(k!(n-k)!)`；
- 容斥：`|A∪B|=|A|+|B|-|A∩B|`；
- 鸽巢原理：多于 `m` 个对象放入 `m` 个盒子，至少一盒有两个对象。

计数能在编码前暴露不可行方案：枚举全部子集有 `2^n` 个状态，排列有 `n!` 个叶子。剪枝改善实际搜索，却不自动改变最坏阶。

## 递推与渐近增长

渐近复杂度描述输入规模增大时的增长阶，并忽略常数与低阶项，但工程决策仍要考虑常数、缓存和输入范围。`O` 是上界，`Ω` 是下界，`Θ` 是紧确阶；说“复杂度是 O(n²)”不排除它其实也是 `O(n³)`，应尽量给紧确界。

# 图作为关系模型

图的顶点表示对象，边表示关系。建模必须声明：

- 边是否有向、是否带权；
- 是否允许自环、重边；
- 路径、可达性和连通分别代表什么业务语义；
- 边不存在表示“无关系”还是“信息未知”。

DAG 支持拓扑序，适合依赖构建；等待图中的环可能意味着死锁；权限图中的可达路径可能意味着权限继承。树是连通无环图，但真实目录有符号链接、服务有共享依赖时未必仍是树。

# 工程推理模板

面对一句技术结论，依次写：

```text
定义域：讨论哪些输入和环境？
前提：哪些约束必须成立？
结论：是全称、存在、上界还是经验观察？
证据：证明、实验还是统计相关？
反例：放宽哪个前提就可能失败？
```

例如“哈希表查询是 O(1)”应改为：在散列质量、负载因子和扩容策略合理时，期望/均摊查询接近常数；最坏仍可能线性。

# 检查理解

1. `P → Q` 的逆命题和逆否命题分别是什么，哪个与原命题等价？
2. 如何用不变量与终止度量证明一个循环完整正确？
3. 偏序与全序的区别为何会影响任务调度？
4. 为什么一个反例能推翻全称命题，却不能证明其反命题对所有输入成立？

> 离散推理把模糊经验转成带定义域和前提的命题。集合与关系描述结构，计数估算状态空间，图描述依赖；证明、不变量和反例共同约束程序与系统结论。
