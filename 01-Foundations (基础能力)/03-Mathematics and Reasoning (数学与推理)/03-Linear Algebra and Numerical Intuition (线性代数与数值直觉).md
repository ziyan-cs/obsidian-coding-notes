> [!abstract] 学习目标
> 建立向量、矩阵、范数和线性变换直觉，理解向量检索的相似度语义，并识别浮点误差、数值稳定性和条件敏感问题。

# 向量与线性组合

向量既可以表示几何方向，也可以表示一组有序特征。只有维度和每一维含义一致的向量才可直接运算。

```text
a + b：逐分量相加
c·a：按标量缩放
Σ cᵢvᵢ：向量的线性组合
```

一组向量若没有任何一个能由其他向量线性组合得到，则线性无关。基是能唯一表示空间中所有向量的线性无关集合；维度是基中向量数量。embedding 的“维度”是表示空间坐标数，不等于可解释业务特征数。

# 矩阵是线性变换

`m×n` 矩阵把 `n` 维输入映射到 `m` 维输出。矩阵乘法 `AB` 要求 A 的列数等于 B 的行数，通常 `AB != BA`。

从三种视角理解 `Ax`：

- A 的行分别与 x 做点积，得到输出分量；
- x 的各分量作为系数，对 A 的列做线性组合；
- A 对空间进行旋转、缩放、投影或这些操作的组合。

转置交换行列。单位矩阵保持向量不变。可逆矩阵表示一一对应的线性变换，但工程求解通常不应显式计算逆矩阵，而应使用分解和成熟数值库。

# 内积、范数、距离与相似度

```text
dot(a,b) = Σ aᵢbᵢ
||a||₂ = sqrt(Σ aᵢ²)
cos(a,b) = dot(a,b) / (||a||₂ ||b||₂)
distance₂(a,b) = ||a-b||₂
```

点积同时受方向和长度影响；余弦相似度消除正尺度影响，更关注方向。向量已做 L2 归一化时，最大化点积、最大化余弦与最小化欧氏距离具有紧密对应关系；未归一化时不能混用排序结论。

零向量没有定义良好的余弦相似度。不同 embedding 模型、不同版本或不同预处理产生的向量通常不处于可直接比较的同一空间。

# 向量检索的工程边界

Top-K 近邻只表示在选定模型和度量下最接近，不证明事实正确、授权允许或业务相关。检索系统要同时决定：

- 文本切分和 embedding 模型；
- cosine、inner product 或 L2 度量；
- exact search 还是 ANN 索引；
- 索引参数、召回率、延迟与内存；
- 过滤条件是在检索前还是检索后执行；
- 用什么真实查询集和相关性标注评估。

维度增加会提高存储与计算成本，不保证质量提高。量化降低带宽和内存，也可能损失召回；必须联合评估 recall@k、延迟、成本和下游任务质量。

# 浮点数为何不等于实数

有限位二进制浮点只能精确表示有限集合。常见误差包括：

- **舍入**：`0.1` 等十进制小数无法精确表示；
- **吸收**：极小数加到极大数上可能不改变结果；
- **消减**：两个接近的大数相减，显著数字大量丢失；
- **溢出/下溢**：结果超出指数范围或接近零；
- **累积误差**：长序列求和对顺序敏感。

浮点加法不满足数学上的结合律，因此并行归约或编译优化可能改变末位结果。货币等需要精确小数语义的领域应使用整数最小单位或十进制定点/高精度类型。

# 比较与稳定算法

只用固定绝对误差不适合所有量级。常见近似比较结合绝对与相对容差：

```cpp
bool nearly_equal(double a, double b,
                  double abs_tol, double rel_tol) {
    double diff = std::abs(a - b);
    return diff <= std::max(abs_tol,
                            rel_tol * std::max(std::abs(a), std::abs(b)));
}
```

容差必须由问题量纲和误差预算决定，不能复制万能 epsilon。NaN 与无穷还需单独处理。

softmax 应先减去最大输入，避免 `exp` 溢出：

```text
softmax(xᵢ) = exp(xᵢ - m) / Σ exp(xⱼ - m)，m=max(x)
```

求和可用更高精度、pairwise summation 或 Kahan 补偿改善误差。稳定算法的目标是在相同数学问题下减少舍入放大。

# 条件数与误差来源

**问题条件性**描述输入微小变化会让真实答案变化多少；**算法稳定性**描述实现额外放大多少数值误差。病态问题即使用稳定算法也可能对输入噪声敏感。排查时要区分：数据本身不可辨识、数学问题病态，还是代码算法不稳定。

# 检查理解

1. 点积大为什么不一定意味着余弦相似度高？
2. 向量归一化后，点积、余弦和 L2 排序有什么联系？
3. 为什么并行求和可能与串行结果末位不同？
4. 数值不准时，如何区分问题病态与算法不稳定？

> [!summary] 本篇结论
> 线性代数提供表示与变换语言，数值分析约束这些数学对象如何在有限精度机器上可靠计算。向量相似度是模型和度量下的证据，不是事实或权限证明。
