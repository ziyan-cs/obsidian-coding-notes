# 概率：在信息条件下描述不确定性

样本空间包含可能结果，事件是其子集。条件概率：

```text
P(A | B) = P(A ∩ B) / P(B)，P(B) > 0
```

独立要求 `P(A∩B)=P(A)P(B)`，不能凭“看起来无关”假设。互斥事件除非概率为 0，否则并不独立。

## 贝叶斯更新与基率

```text
P(A | B) = P(B | A)P(A) / P(B)
```

监控告警中，`A` 可表示真实故障，`B` 表示告警。即使检测器在故障时大概率告警，若故障基率极低，告警中误报仍可能很多。必须同时看：

- precision：告警中有多少是真故障；
- recall：真实故障中有多少被发现；
- false-positive rate：正常时误报概率；
- 漏报和误报各自的业务代价。

# 随机变量、期望与方差

期望是长期加权平均，不保证一次观测接近期望；线性性质不要求变量独立：

```text
E[X + Y] = E[X] + E[Y]
```

方差 `Var(X)=E[(X-E[X])²]` 衡量围绕均值的离散程度。独立变量之和的方差可相加；存在相关性时还要考虑协方差。

常见分布只在假设成立时使用：Bernoulli 表示一次成功/失败；Binomial 表示固定次数独立同分布试验的成功数；Poisson 常近似一定时间窗口的稀疏独立到达；Exponential 具有无记忆性。真实流量常突发、自相关，不能机械套 Poisson。

# 统计：从样本推断总体

## 中心、离散与尾部

- mean 容易被极端值拉动；median/P50 更稳健；
- P95/P99 表示样本中相应比例不超过该值，不代表“最慢请求”；
- 标准差适合描述部分近似对称分布，长尾延迟更应直接看直方图和分位数；
- 不同实例的 P99 不能直接平均得到全局 P99，需合并可聚合直方图或原始样本。

分位数估计取决于样本量和实现算法。P99 若只有 100 个样本，几乎由极少数值决定，不能过度解读。

## 抽样误差与系统偏差

随机误差可随样本增多而下降；选择偏差、幸存者偏差、只统计成功请求等系统偏差不会靠“大样本”自动消失。压测要记录预热、运行时长、负载生成方式、失败请求和环境噪声。

置信区间表达“按该构造方法重复采样，区间覆盖真实参数的长期比例”，不应解释为“参数有 95% 概率落在已经算出的固定区间内”。比较两个版本时同时报告效应大小和不确定性，不只看一个 p-value。

# Little 定律

稳定系统、口径一致且观察时间足够时：

```text
L = λW
平均在途量 = 平均有效到达/完成率 × 平均停留时间
```

若稳定服务完成 1000 req/s，平均停留 0.2 s，则平均约 200 个请求在系统内。`W` 包括排队与服务时间；单位必须一致。Little 定律不要求到达服从 Poisson，也不直接给出 P99。

# 利用率、排队与饱和

单服务台理想 M/M/1 模型中，`ρ=λ/μ<1` 才稳定，平均系统停留时间为：

```text
W = 1 / (μ - λ)
```

它说明利用率接近 1 时等待非线性上升，但真实服务往往不是 M/M/1：线程池有多个服务台，服务时间非指数，到达会突发，还受锁和下游限制。公式用于直觉和粗检验，不用于替代测量。

## 过载与重试

队列无限增长会把快速失败变成长超时，并占用内存、连接和线程。工程措施包括有界队列、deadline、背压、负载丢弃和容量余量。

若每次失败平均触发 `r` 个额外重试，重试成功与延迟又会影响后续请求；无退避重试可能形成正反馈。应使用指数退避、随机抖动、重试预算和幂等语义，并观测**包含重试的总尝试率**。

# 测量清单

```text
工作负载：请求构成、数据规模、并发/到达模型
结果：吞吐、P50/P95/P99、错误率、队列长度
资源：CPU、内存、I/O、连接池与下游限制
统计：样本量、预热、重复轮次、置信范围
偏差：失败请求是否计入，是否 coordinated omission
```
