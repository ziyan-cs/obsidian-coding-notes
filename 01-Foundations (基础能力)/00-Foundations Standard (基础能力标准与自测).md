> [!abstract] 完成标准
> 不以“读过”为完成，而以能够解释、推导、编码和排查为准。基础模块合格后，你应能把程序行为连接到数据表示、编译执行、操作系统和算法复杂度。

# 计算机系统模型

- [ ] 能从源代码讲到预处理、编译、汇编、链接、装载和进程执行，并定位常见阶段错误。
- [ ] 能解释二进制、补码、浮点数、字节序、对齐与溢出为什么会影响程序正确性。
- [ ] 能区分进程、线程、虚拟内存、文件与系统调用，知道用户态和内核态的边界。
- [ ] 能用时间局部性、空间局部性和缓存层次解释一段代码的性能差异。

# 数据结构与算法

- [ ] 能独立实现并分析数组、链表、栈、队列、哈希表、堆、树和图的核心操作。
- [ ] 能写出二分、排序、双指针、滑动窗口、回溯、贪心和动态规划的适用条件，而非只背模板。
- [ ] 能说明时间复杂度、空间复杂度、均摊复杂度以及输入规模之间的关系。
- [ ] 面对新题时能先定义状态、约束和不变量，再选择数据结构与算法。

# 基础实践

- [ ] 能在 Linux 终端完成文件、进程、权限、管道和文本处理的日常操作。
- [ ] 能读懂简单汇编、调用栈和调试器输出，把崩溃位置映射回源代码。
- [ ] 能为一个小程序准备输入边界、运行验证和复杂度说明。

# 综合自测

1. 为什么 `0.1 + 0.2` 可能不等于精确的 `0.3`，工程上应如何比较？
2. 一个程序从磁盘上的可执行文件变成正在运行的进程，经历了哪些关键步骤？
3. 为什么哈希表平均查找是 `O(1)`，却不能据此保证每次查找都是常数时间？
4. 给定一个陌生问题，你能否写出暴力解、瓶颈和至少一种优化依据？
