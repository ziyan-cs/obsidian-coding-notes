> **核心考点**：面试常见数据速记——2的幂、整型范围、位运算结论、ASCII、补码、时间/端口常量

## 2 的幂

```c++
2^8  = 256
2^10 = 1024 (1K)
2^12 = 4096 (4K)
2^16 = 65536 (64K)
2^20 = 1048576 (1M)
2^30 = 1073741824 (1G)
2^32 = 4294967296 (4G)
```

## 整型取值范围

```cpp
char(1B):   signed -128~127          unsigned 0~255
short(2B):  signed -32768~32767      unsigned 0~65535
int(4B):    signed -2147483648~2147483647  unsigned 0~4294967295
long long(8B): signed -2^63~2^63-1   unsigned 0~2^64-1
```

## 进制 & 全 1 规律

```c++
1 Byte = 8 bit
1位十六进制 = 4位二进制
8位全1 = 0xFF = 255
16位全1 = 0xFFFF = 65535
n位全1 = 2^n - 1
```

## 位运算结论

```c++
x & (x-1)    // 消除最低位1，统计1的个数
x & (-x)     // 取最低位1（lowbit）
x & 1        // 取最低位，判断奇偶
x << 1       // 等价 ×2
x >> 1       // 等价 ÷2（有符号负数向下取整）
~x           // 按位取反，~x = -x - 1
a ^ a = 0    // 自反性
a ^ 0 = a    // 恒等
```

## ASCII 必背

```c++
'0' = 48    'A' = 65    'a' = 97
大小写差值 = 32
```

## 补码核心

```c++
正数：原码 = 反码 = 补码
负数补码：数值位取反 + 1
负数最小值绝对值 = 正数最大值 + 1
```

## 时间与网络常量

```c++
struct timeval { long tv_sec; long tv_usec; };  // 秒 + 微秒
struct timespec { long tv_sec; long tv_nsec; }; // 秒 + 纳秒

1s = 1000ms = 1,000,000μs = 1,000,000,000ns
TCP 端口范围: 0~65535（1-1023 特权端口）
MTU: 1500 字节（以太网）
MSS: 1460 字节（MTU - IP头20 - TCP头20）
```
