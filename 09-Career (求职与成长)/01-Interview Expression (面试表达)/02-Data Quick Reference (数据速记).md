# 数量级与数据表示
## 2 的幂速记

> [!tip]- 记忆口诀
> "2^10 = 1K，往后每多 10 次方就多一个量级"

```c++
2^8  = 256
2^10 = 1024 (1K)
2^12 = 4096 (4K)
2^16 = 65536 (64K)
2^20 = 1048576 (1M)
2^30 = 1073741824 (1G)
2^32 = 4294967296 (4G)
```

## 整型取值范围

> [!warning] 面试高频陷阱
> 以下字节数是常见平台（如 LP64/LLP64）上的经验值，不是 C++ 标准对所有实现的保证；用 `sizeof`、`std::numeric_limits<T>` 或固定宽度类型 `std::int32_t` / `std::int64_t` 表达真正的约束。`size()` 返回 `size_t`，与有符号数比较前要先检查语义和转换。

```cpp
char(1B):   signed -128~127          unsigned 0~255
short(2B):  signed -32768~32767      unsigned 0~65535
int(4B):    signed -2147483648~2147483647  unsigned 0~4294967295
long long(8B): signed -2^63~2^63-1   unsigned 0~2^64-1
```

## 进制 & 全 1 规律

```c++
1 Byte = 8 bit
1位十六进制 = 4位二进制
8位全1 = 0xFF = 255
16位全1 = 0xFFFF = 65535
n位全1 = 2^n - 1
```

## 位运算结论

> [!tip]- 面试高频用法
> 位运算考的不多但一考就是关键。`x & (x-1)` 和 `x & (-x)` 是两大高频考点。

```c++
x & (x-1)    // 消除最低位1，统计1的个数
x & (-x)     // 取最低位1（lowbit）
x & 1        // 取最低位，判断奇偶
x << 1       // 非负且不溢出时可视为 ×2；有符号溢出不是安全技巧
x >> 1       // 对负数的行为/取整语义需按语言版本与实现确认；不要用它代替普通除法表达业务
~x           // 按位取反，~x = -x - 1
a ^ a = 0    // 自反性
a ^ 0 = a    // 恒等
```

```c++
正数：原码 = 反码 = 补码

```

# 时间、网络与系统常量
## 时间与网络常量

| 常量 | 值 | 说明 |
|------|------|------|
| 1s | 1000ms = 10^6μs = 10^9ns | |
| TCP 端口范围 | 0~65535 | 1-1023 特权端口需 root |
| MTU | 常见以太网为 1500 字节 | 路径与链路配置可不同 |
| MSS | 常见 IPv4 无选项时为 1460 字节 | 由路径 MTU 与实际 IP/TCP 头部决定 |
| MSL | 实现/协议栈相关 | 报文最大生存时间的抽象概念 |
| TIME_WAIT | 实现与配置相关 | 不应死记固定 2MSL 秒数 |

## Linux 常用数值

> [!tip]- 面试速记
> SIGKILL(9) 和 SIGTERM(15) 的区别是面试常问：9 不能被捕获/忽略，15 可以。

```c++
stdin=0  stdout=1  stderr=2               // 文件描述符
PATH_MAX = 4096                           // 路径最大长度
PIPE_BUF = 4096                           // 管道原子写入上限
SIGINT=2  SIGKILL=9  SIGTERM=15           // 常见信号
O_RDONLY=0  O_WRONLY=1  O_RDWR=2          // open flags
EPOLLIN=0x001  EPOLLOUT=0x004  EPOLLET=0x80000000  // epoll 事件
```
