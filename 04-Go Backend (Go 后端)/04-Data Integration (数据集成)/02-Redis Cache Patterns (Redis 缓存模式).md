> [!abstract] 一句话结论：缓存是派生数据，不是新的真相来源；设计先明确回源、失效、击穿保护和一致性边界。

## Cache-Aside 基线

1. 读：缓存命中直接返回；未命中从数据库读取并填充缓存。
2. 写：先更新数据库，再删除或更新缓存；选择必须与并发和失败处理匹配。
3. 失效：设置合理 TTL，并为热点、穿透、雪崩配置专门保护。
