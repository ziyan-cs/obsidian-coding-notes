# Vault Map — 从这里开始

> **一句话目标**：两年后，你能用 C++ 解释底层与性能问题，用 Go 交付清晰可靠的后端服务，用 Python 加速测试、自动化和数据分析。

## 你现在在哪里

- 身份：大学阶段系统学习的起点。
- 已有主线：C++ 后端知识树。
- 新增主线：Go 从零建立业务服务能力；Python 从零建立工程辅助能力。
- 学习原则：**理解 → 最小代码 → 小功能 → 复习 → 讲解**。只读不算掌握。

## 知识主干与顺序

```text
CS Core ──┐
Linux ────┼──> C++：资源 / 并发 / 网络 / 性能 ──> 后端项目
Network ──┤                 │                         │
Database ─┘                 ├──> Go：服务端工程 ──────┤
                            └──> Python：测试与自动化 ┘
```

1. **基础层**：`01` 操作系统与组成原理，`02` 数据结构算法，`04` Linux，`05` 网络，`06` 数据库。
2. **C++ 主线**：`03` 的生命周期、所有权、并发、网络模型、工程化与性能。
3. **服务端主线**：`08` Redis / MQ / 分布式协议，再进入 Go 服务与项目。
4. **能力证明**：`12` 项目、压测、故障复盘；`09` 面试表达与校招材料。

## 每次学习的最小闭环（60–90 分钟）

1. 选一个原子主题，先写下“我猜它解决什么问题”。
2. 阅读并运行一个最小例子；改一个参数，观察失败或边界行为。
3. 用自己的话写 3 条结论、1 个反例、2 道自测题。
4. 在 [[02-Spaced Review System]] 记录下一次复习日；出错则写入 [[05-Mistake Log]]。

## 不做什么

- 不为“完整”收集大段解释，却没有代码、题目或项目落点。
- 不为了追新把所有语言、库和版本都学一遍。
- 不把 C++、Go、Python 的同名机制简单等同；必须记录差异与适用边界。
