> [!abstract] 维护范围
> 收集笔记本身的事实、示例、结构或链接问题。学习任务看[学习周期](/00-Hub%20(学习入口)/09-Study%20Cycle%20(学习周期).md)，个人误解记入[错误记录](/00-Hub%20(学习入口)/05-Mistake%20Log%20(错误记录).md)。

# 先处理什么

| 优先级 | 问题 | 完成依据 |
| --- | --- | --- |
| P0 · 会误导或阻断使用 | 错误结论、代码与解释矛盾、关键入口失效 | 有来源或复现，修正后验证 |
| P1 · 妨碍当前学习 | 缺少前置解释、示例跳步、必要内容遗漏 | 能顺着理解并验证 |
| P2 · 结构与观感 | 拼接残留、重复内容、标题或拆分不当 | 大纲自洽，相关链接仍有效 |
| P3 · 低频维护 | 暂不影响当前学习的版本提示、来源补全 | 说明适用范围并补充依据 |

时效问题按影响定级：过时内容若已导致错误或安全风险，优先修复，不固定放到 P3。

# 待处理事项

发现问题时在这里添加一行：

```md
- [ ] P1 · [笔记名](根路径)：位置与现象；依据：来源或复现；完成条件：怎样确认修好。
```

修复时先看上下文，再改相关段落；调整路径时检查入链，修改教学代码时运行相应例子。验证完成后移出队列，不堆积已完成清单。

没有待处理条目只表示暂无记录；结构检查通过也不等于所有知识结论已被证明。
