# 处理优先级

1. **P0：正确性** — 错误事实、失效链接、正文与代码矛盾；附来源或最小复现并检查入链。
2. **P1：可学习性** — 当前主线缺少必要解释、流程或验证；先修正在学内容。
3. **P2：结构与可读性** — 大纲混乱、拼接残留、重复或错误拆分；验收 Obsidian 大纲与链接。
4. **P3：时效与低频内容** — 按实际需要复查版本、API、参数和性能结论。

新增事项写成：`文件与位置 → 现象 → 证据 → 验收条件`；修复并验证后移出队列。结构检查不等于每条事实都已逐项证明，因此不记录笼统的“全库已无问题”。
