# 每次学习的闭环

1. 开始模块前浏览能力标准，明确本轮要获得的可观察能力。
2. 按目录与文件编号学习，运行示例并记录无法解释的现象。
3. 学完后不看正文完成勾选和综合自测；答不出时回到具体笔记补证据。
4. 仅为真正需要再次回忆的笔记设置 `review_due`，按实际表现调整日期。
