> [!abstract] 长期方向
> C++ 建立资源、并发与性能直觉，Python 支持自动化和验证，Go 用于后续服务开发。具体任务只在[学习周期](09-Study%20Cycle%20%28%E5%AD%A6%E4%B9%A0%E5%91%A8%E6%9C%9F%29.md)维护。

# 能力如何连接

| 学习进程 | 建立的能力 | 可观察的结果 |
| --- | --- | --- |
| 基础程序 | 计算机运行、C++ 与 Python 基础、调试和测试 | 两个程序可运行，有边界测试 |
| C++ 资源与构建 | 对象、所有权、构建与内存诊断 | 组件可构建、可测试，能解释失败路径 |
| HTTP 小服务 | Linux、TCP、HTTP 与接口验证 | 能处理请求，验证错误和关闭流程 |
| Go 数据服务 | SQL、事务、Go 类型与服务生命周期 | API 可持久化、回滚并可靠退出 |
| 主项目 | 需求、数据、安全、故障和性能 | 项目可复现，有测试与运行证据 |
| 专项深化 | 并发性能、分布式、云原生、安全或 AI | 验证与项目或岗位相关的问题 |
| 系统设计与表达 | 容量推导、项目深挖、作品与面试复盘 | 结论对应代码、测试和测量结果 |

# 如何把握深度

**主线扎实**：语言、系统、网络与数据库需要能独立解释和验证。Python 与 C++ 交错起步，Go 在基础 HTTP 和 SQL 之后承接服务交付；算法穿插练习，不阻塞项目推进。

**项目贯穿**：前期用短程序验证机制，中期组织小型服务，后期选一个主项目持续深化。先把一个系统做透，再决定是否增加项目或组件。

**专项有依据**：安全边界在项目实现前考虑；云原生、分布式、平台和 AI 基础设施结合实际服务问题或目标岗位深入。

**进度可调整**：读不懂时补前置，已掌握时通过验证后继续。
