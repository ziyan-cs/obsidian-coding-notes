# 能力路线

| 阶段 | 学习主线 | 进入下一阶段的证据 |
| --- | --- | --- |
| 基础启动 | 计算机系统、算法基础、C++ 语言与对象、Python 基础；从第一天使用 Git、构建与测试 | 多文件 C++ 程序可构建测试；Python 项目可复现；能解释源码到运行的链路 |
| 工程与系统 | 现代 C++、数据结构、并发、Linux、网络、调试与性能验证 | 小型网络组件可运行；有测试、诊断和测量记录 |
| 数据与服务 | SQL/MySQL、缓存、消息与分布式基础，再进入 Go、并发、Web 与数据集成 | API 有持久化、超时、错误处理、测试和基本可观测性 |
| 项目与运行 | 选择一个后端项目，逐步加入部署、可靠性、安全与恢复 | 能演示系统，并用证据解释一致性、容量、故障和回滚取舍 |
| 专项扩展 | 按项目需要深化 Kubernetes/平台工程、安全工程、AI 应用与基础设施 | 能说明专项能力如何服务真实系统，而非只会罗列工具 |
| 求职表达 | 项目证据、系统设计、简历与面试训练贯穿后期 | 两个左右的项目可复现、可追问，结论有代码或测量支撑 |

# 推进原则

- C++ 建立资源、并发与性能直觉；Python 用于自动化、验证与数据处理；Go 在服务基础具备后深化。
- 算法、工程实践和复习贯穿主线；云原生、安全、AI 不替代系统、网络、数据和服务基础。
- 阶段按可验证产物推进，不按日期或勾选数自动升级。卡住时回到缺失的前置知识。
