> [!abstract] 两个属性即可
> `study_stage` 表示当前学习状态或下一次复习阶段，`review_due` 预留复习日期。首次学懂后，手动改为 `D1` 并填写次日日期；不记录首次学习日期。

# 完成后怎么改

| 实际进度 | 属性操作 |
| --- | --- |
| 尚未开始 | `backlog`，保留空的 `review_due:` |
| 正在学，尚未读懂 | 可改为 `learn`，复习日期仍留空 |
| 首次学懂并完成小验证 | 改为 `D1`，日期设为完成日的次日 |
| 完成一次复习 | 按下表进入下一阶段，从实际完成日计算日期 |
| 核心机制仍答不出 | 补学后改为 `D1`，日期设为次日 |
| 长期稳定掌握 | 改为 `solid`，清空复习日期；遇到问题再安排 |

# 复习间隔

下表是可调整的默认节奏。D1、D3 等保留为阶段名称；延期后从实际完成日继续计算间隔，因此不必保存首次学习日期。

| 本次完成 | 下一阶段 | 距本次完成 |
| --- | --- | --- |
| 首次学习 | D1 | 1 天 |
| D1 | D3 | 2 天 |
| D3 | D7 | 4 天 |
| D7 | D14 | 7 天 |
| D14 | D30 | 16 天 |
| D30 | D60 | 30 天 |
| D60 | solid，或保留 D60 | 稳定则清空日期；仍需巩固可再隔 30 天 |

先合上笔记解释核心机制，再验证一个例子或边界，最后查漏。不必每次重读全文；容易的主题可以延长间隔，困难的主题缩短间隔。

# 查看与积压处理

在电脑端、笔记库根目录运行：

```powershell
.\List-ReviewDue.ps1
.\List-ReviewDue.ps1 -All
```

默认显示逾期、当天和明天；`-All` 显示所有已填写复习日期的笔记。空的 `review_due:` 不会出现在列表中。脚本只读取和输出，不会更新状态或推进阶段。平板上直接修改笔记顶部属性即可。

没复习就保留原状态和日期；确需调整安排时只改日期，不把阶段提前。积压时优先近期错误、当前前置与项目所需内容，也可暂停新学。新学顺序仍在[学习周期](/00-Hub%20(学习入口)/09-Study%20Cycle%20(学习周期).md)，字段格式见[笔记规范](/00-Hub%20(学习入口)/03-Note%20Standard%20(笔记规范).md)。
