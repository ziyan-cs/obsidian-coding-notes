> [!abstract] 学习定位：C++ 后端主线以资源生命周期为核心：先写对对象与所有权，再写对并发、网络和性能，最后用工程证据证明它可靠。

# 六个二级模块

1. `01-Language Basics`：语法和基本表达能力。
2. `02-Object and Resource Model`：对象、内存、RAII 与多态。
3. `03-Modern C++`：移动、智能指针、泛型与现代工具。
4. `04-STL and Data Structures`：容器、迭代器、算法库。
5. `05-Concurrency and Performance`：线程、同步、内存序与性能。
6. `06-Engineering Practice`：构建、调试、测试、观测与交付。

# 学习原则

每个主题都要能回答：资源由谁拥有、何时释放、并发时谁负责同步、失败时如何观测与恢复。
